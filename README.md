# CAD

Ny webbsajt.

## Kom igång lokalt

```bash
git clone https://github.com/joachimjohansson/cad.git
cd cad
```

Öppna `index.html` direkt i webbläsaren, eller starta en lokal server:

```bash
python3 -m http.server 8000
```

och gå till http://localhost:8000.

## Struktur

```
index.html        Startsida
css/style.css     Stilmall
js/main.js        JavaScript
assets/images/    Bilder
```
